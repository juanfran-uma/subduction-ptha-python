Rates

3. Bird or Bird + Griffin, per zone

Step 3 takes the plate convergence from a table of plate-boundary pieces. Two tables are in the package, and generate.py --convergence picks one. For most PTHA18 zones they give the same or nearly the same answer. For the zones where PTHA18 used Jonathan Griffin's plate rates instead of Bird's steps (eastern Indonesia and New Guinea), they can differ by anything from about 10% to a factor of 38 (seramsouth). This page says which zone uses which table, measured on PTHA18's own meshes.

At a glance

python ptha_python/generate.py kermadec --zone kermadectonga2 --folder kermadectonga2 # bird (default)
python ptha_python/generate.py kermadec --zone kermadectonga2 --folder kermadectonga2_bg --convergence bird-griffin # PTHA18's table

generate.py prints, for any PTHA18 zone, where PTHA18 took its convergence from and what both tables give on PTHA18's mesh (from the table on this page). In an existing folder, change BIRD_TABLE in steps/step3_convergence.py and re-run steps 3, 6 (--force), 7 and 9. The choice is recorded in data/convergence_per_column.json (bird_table). Step 8, the official run, always uses bird-griffin, as PTHA18 did.

What "Griffin's traces" are

PTHA18 did not use Bird's file as it is. Its R scripts in rptha/R/examples/austptha_template/DATA/BIRD_PLATE_BOUNDARIES/ start from Bird's (2003) plate model, edited so that some of its pieces were replaced by other information, and combine it with "the plate motion rates put together by Jonathan Griffin for eastern Indonesia and other new source zones". A merge step then produces the one table PTHA18's rate code reads. The table has a column collator that says who supplied each row: Bird2003_subset (Bird's steps kept by PTHA18), JG (Griffin's traces) or GD (rows added by Gareth Davies, for example the Arakan trace at 23 mm/yr).

Why the numbers differ so much where Griffin's traces are used: Bird's model divides the region between Australia and the Pacific into many small plates (Bird's Head, Caroline, Woodlark, Manus, Molucca Sea, Banda Sea and others), and each boundary carries only its own share of the motion. Griffin's trace of the New Guinea trench carries most of the Pacific-Australia motion, so it gives a much larger rate there. Neither is wrong: they are two models of the same plates. bird is Bird's model as published; bird-griffin is PTHA18's.

The measurements are in ptha_python/data/bird/ptha18_convergence_sources.csv, which generate.py reads for its note. Its columns: zone, row_weight, use_bird_convergence, constant_mm_per_yr (35 for the puysegur zones), columns (number of along-strike columns of PTHA18's mesh), cols_bird, cols_griffin, cols_davies (columns matched to each source), traces, source (bird, mixed or griffin), conv_bird_griffin, conv_bird (mm/yr) and lon_c, lat_c (centre of the mesh). "bird vs b-g" is the public table's value relative to PTHA18's table. "row_weight 0": PTHA18's zone table gives this zone weight 0 in its logic tree.

Notes

  • 1. puysegur and puysegur2: PTHA18 did not use either table there but a constant 35 mm/yr (use_bird_convergence = 0). Both tables give nearly the same Bird value there (21.9 mm/yr on puysegur's mesh, 24.9 on puysegur2's), because PTHA18's table has Bird's own steps there. To use PTHA18's value, set CONVERGENCE_OVERRIDE_MM_PER_YR = 35 in step 3 (details).
  • 2. Zones PTHA18 used Bird on, where the two tables still differ (hjort, the two Macquarie zones, sandwich, newhebrides2): PTHA18's table kept some of Bird's steps of other boundary types, such as oceanic transform faults and, on the Macquarie Ridge, a spreading ridge. bird uses only the convergent types (SUB, OCB, CCB), so there it matches a farther convergent step. On the Macquarie Ridge, where the boundary is mostly a transform, that changes the value a lot (7.2 against 17.0 mm/yr on macquarieislandnorth's mesh).
  • 3. solomon, solomon2, sunda, sunda2: a few columns are matched to a trace of Griffin's or Davies' table (one column to trobriand on solomon and solomon2; 32 of 123 columns on sunda and 31 of 120 on sunda2 to Davies' Arakan trace). The zone values differ by 3% or less.
  • 4. Zones PTHA18 never modelled (for example Calabria): the Bird + Griffin table has no steps near them, so bird-griffin falls back to Bird's public catalogue, and the two give the same answer.
  • 5. Eastern-Indonesia zones (timor, flores, seram, tolo, sangihe, manus, mussau, trobriand, moresby_trough and others): their convergence in PTHA18 comes from Griffin's traces, which the public table does not have. The package builds a zone only when it has a Berryman et al. (2015) mapping (note 6).
  • 6. Zones with no Berryman mapping (marked in the table): step 1 needs the zone's seismogenic cutoff, which with --ptha false comes from Berryman et al. (2015) through ZONE_TO_BERRYMAN_SEGMENTS in lib/berryman_params.py. Without an entry step 1 stops. To build one, add the zone there and in ZONE_DOMINANT_SEGMENT, pointing at its Berryman row.
