Code

Code map

Every Python file of the package, what it does, and which file of rptha it corresponds to. The modules of the engine are ports of a named rptha file, or are marked as new. The R file names below are the names used in the rptha repository (github.com/GeoscienceAustralia/ptha, BSD 3-Clause). The rptha R package source is not included in this repository, only a few of its data files (rptha/: the parameter table sourcezone_parameters.csv and two shapefiles).

At a glance

The engine itself is pyptha/. The script that runs it for one zone is logic_tree/run_logic_tree.py, the steps are templates/ (turned into scripts by generate.py), and the helper modules are lib/. Step 8 runs PTHA18's own inputs through the same engine. The tables below list every file, grouped by the steps that use it.

Engine examples

pyptha/examples/ holds four scripts that use the engine directly, without the steps: new_zone.py (ruptures and rates for an idealised planar zone; mirrors produce_unit_sources.R and single_source_rate_computation.R), puysegur_real.py (the same from the Puysegur contours shipped in rptha/), single_source_rate_computation.py (the Python equivalent of single_source_rate_computation.R) and stochastic_slip_ruptures.py (heterogeneous slip for a new zone). Each runs with python ptha_python/pyptha/examples/NAME.py.

Reading both codes side by side

Read a Python function next to the R function it ports. The names are kept close on purpose, and the module docstrings say which R file and which lines each part comes from. Where the Python code departs from rptha, the docstring says so and gives the reason. The defaults differ from PTHA18 in two places: the run uses public data only (--ptha false) and Bird (2003) for convergence (--convergence bird). The mesh, column, cell-size and rupture rules are PTHA18's own unless an option says otherwise. The options are described on the pages discretiser and cell size.

Agreement with PTHA18 is measured, not assumed. The checks in Validation compare the Python results with PTHA18's published files, and say what each check covers.

Not portedThe tsunami simulation and the hazard-curve steps of rptha are not in this package. The package stops at earthquake rates, and the rest of the PTHA18 chain is not reproduced here.
The file names are taken from the module docstrings of ptha_python/ and official_ptha_data/.
