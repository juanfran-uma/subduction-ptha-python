# Calabria

Generated by `ptha_python/generate.py` for the SLAB2.0/SLAB1.0 region
"Calabria" (ScienceBase item 5aa31058e4b0b1c392ea3e63, prefix
"cal"), matched to the source zone `calabria2`.

## Settings of this run

| | |
|---|---|
| Geometry | SLAB: the trench is the up-dip edge of the raster, contours every 5 km below the nearby trench; zone cut at Berryman et al. (2015)'s end points ((15.775, 37.282), (17.415, 39.071)) |
| Mesh | `--columns trench`, `--discretizer optimal`, cells of about 50 km |
| Rupture size | local: each rupture is sized from the real km of the cells where it sits, with the overlap correction q |
| Segmentation | off (LEVEL 0 weight 1) |
| Shear modulus | constant 30 GPa (step 7c only runs with --force) |
| Plate convergence | Bird (2003) |
| PTHA18 files | steps 1-7 and 9 read none (`--ptha false`); only step 8 does |

## Inputs taken from the literature

| | |
|---|---|
| Seismogenic cutoff | 60 km below the trench (Berryman et al. 2015 Table 3.1, dominant segment 'Calabria') |
| Coupling (min/pref/max) | [0.3, 0.5, 0.7] |
| b-value (min/pref/max) | [0.7, 0.95, 1.2] |
| mw_max_observed | 7.1 |
| Unit-source width | 50 km (the general default) |

## Run

One step at a time, from the repository root:

    python examples/new_zones/calabria2/steps/step1_fetch_slab2.py       # SLAB contours (or reads the external mesh)
    python examples/new_zones/calabria2/steps/step2_build_grid.py        # unit-source mesh
    python examples/new_zones/calabria2/steps/step3_convergence.py       # plate convergence per column
    python examples/new_zones/calabria2/steps/step4_fetch_gcmt.py        # GCMT catalogue
    python examples/new_zones/calabria2/steps/step5_subset_gcmt.py       # events of this zone
    python examples/new_zones/calabria2/steps/step6_write_input.py       # the input JSON
    python examples/new_zones/calabria2/steps/step7_run.py               # logic tree, ruptures and rates
    python examples/new_zones/calabria2/steps/step7b_stochastic_slip.py  # HS and VAUS variants (optional)
    python examples/new_zones/calabria2/steps/step7c_variable_mu.py      # variable shear modulus rates (after 7b)
    python examples/new_zones/calabria2/steps/step8_official.py          # PTHA18's official run (optional, needs R)
    python examples/new_zones/calabria2/steps/step9_report.py            # report.html

Or all in one go:

    python examples/new_zones/calabria2/steps/step_total.py

`RUN.html` lists the exact commands this folder was made with.
