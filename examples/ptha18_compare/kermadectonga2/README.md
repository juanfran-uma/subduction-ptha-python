# Kermadec

Generated by `ptha_python/generate.py` for the SLAB2.0/SLAB1.0 region
"Kermadec" (ScienceBase item 5aa318e1e4b0b1c392ea3f10, prefix
"ker"), matched to the source zone `kermadectonga2`.

## Settings of this run

| | |
|---|---|
| Geometry | SLAB: the trench is the up-dip edge of the raster, contours every 5 km below the nearby trench |
| Mesh | `--columns trench`, `--discretizer optimal`, cells of about 50 km |
| Rupture size | rptha's rule: one block of cells per magnitude |
| Segmentation | off (LEVEL 0 weight 1) |
| Shear modulus | constant 30 GPa (step 7c only runs with --force) |
| Plate convergence | Bird (2003) |
| PTHA18 files | steps 1-7 and 9 read none (`--ptha false`); only step 8 does |

## Run

One step at a time, from the repository root:

    python examples/ptha18_compare/kermadectonga2/steps/step1_fetch_slab2.py       # SLAB contours (or reads the external mesh)
    python examples/ptha18_compare/kermadectonga2/steps/step2_build_grid.py        # unit-source mesh
    python examples/ptha18_compare/kermadectonga2/steps/step3_convergence.py       # plate convergence per column
    python examples/ptha18_compare/kermadectonga2/steps/step4_fetch_gcmt.py        # GCMT catalogue
    python examples/ptha18_compare/kermadectonga2/steps/step5_subset_gcmt.py       # events of this zone
    python examples/ptha18_compare/kermadectonga2/steps/step6_write_input.py       # the input JSON
    python examples/ptha18_compare/kermadectonga2/steps/step7_run.py               # logic tree, ruptures and rates
    python examples/ptha18_compare/kermadectonga2/steps/step7b_stochastic_slip.py  # HS and VAUS variants (optional)
    python examples/ptha18_compare/kermadectonga2/steps/step7c_variable_mu.py      # variable shear modulus rates (after 7b)
    python examples/ptha18_compare/kermadectonga2/steps/step8_official.py          # PTHA18's official run (optional, needs R)
    python examples/ptha18_compare/kermadectonga2/steps/step9_report.py            # report.html

Or all in one go:

    python examples/ptha18_compare/kermadectonga2/steps/step_total.py

`RUN.html` lists the exact commands this folder was made with.
